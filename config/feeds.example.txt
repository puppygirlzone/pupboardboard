# pupboard news feeds
#
# Copy this file to feeds.txt (same folder) and edit it:
#   cp config/feeds.example.txt config/feeds.txt
#
# One feed per line, either:
#   Name | https://example.com/feed.xml
#   https://example.com/feed.xml          (the feed's own title is used)
#
# Lines starting with # are ignored, so you can comment feeds out.
# Changes are picked up automatically; no restart needed.
# Any RSS or Atom feed works. Up to 50 feeds.
# Reddit limits how often its feeds can be fetched, so with several subreddits
# one may show as "couldn't load" now and then; it recovers on its own.
